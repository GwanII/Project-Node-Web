16. 투표 위젯 실 데이터 연동 (마감일도 실제 날짜로 변경, 항목 이미지 첨부 시 실제 스토리지 업로드)
17. 새 프로젝트 생성 시 생성자를 자동으로 팀장(`project_members`)으로 등록하고, 생성된 프로젝트로 바로 이동하도록 수정

## 로그인 관련 트러블슈팅

24. 휴대폰 인증번호(OTP)가 실제로 발송되지 않던 문제 — Supabase에 SMS 발송 서비스가 연결되어 있지 않아서였음. 테스트 번호(Test Phone Numbers and OTPs) 등록 방식으로 우회
25. `crypto.randomUUID()`가 `http://192.168.x.x` 같은 비보안 컨텍스트에서 동작하지 않는 문제 확인 및 수정 (Math.random 기반 토큰 생성으로 대체)
26. 핸드폰에서 LAN IP로 접속 시 Google 로그인이 깨지던 문제 원인 규명 (WebCrypto API가 비보안 컨텍스트에서 막혀 PKCE 인증 실패) 및 이메일/휴대폰 인증으로 우회하는 방법 안내
27. 이메일 인증 메일이 오지 않던 문제 — Supabase 기본 이메일 발송 제한/지연 문제로 확인, 개발 단계에서는 "Confirm email" 끄는 방법 안내
